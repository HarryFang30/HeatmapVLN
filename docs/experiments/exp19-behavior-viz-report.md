## 5. 对论文用法的含义

- 可以放：主图 T/F 作为"方法在闭环中的运作过程"的定性展示；图注按预注册只写"预测的历史 affordance map 好于平凡基线
  （PCK@8 0.780 vs 0.299）"。
- 不可以写："历史 affordance map 准确 / 模型记住了来路"（H1 未到 0.80）；"未来 affordance map 与动作一致"（H2 没测出来）；
  "affordance map 驱动 / 改善了决策"（H3 只是 7.5% 的厘米级依赖，且"去哪"在桥之前已定；闭环收益由 EXP-05/07 定为无可测差异）；
  "从视觉中定位历史"（历史头是位姿投影器，EXP-02/03）。
- 如果正文需要一句"如何起作用"：能被这批数据支撑的说法只有"模型内部对来路方向的预测随机器人转向而正确更新（典型路线上
  PCK@8 88–98%），并以记忆的形式注入快系统的条件；这一注入在单步上改变约 7.5% 的动作块、幅度为厘米级"。
