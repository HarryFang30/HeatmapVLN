# EXP-08 / EXP-09 结果：阶段三配方里只有"惩罚重校准"有可测效应

判据见台账 [EXP-08](README.md#exp-08-阶段二联合训练买到了什么) 与
[EXP-09](README.md#exp-09-阶段三配方里哪一项真的在起作用)（2026-09-03 预注册，开跑前 commit）。
提交物 [exp08-exp09-stage3-ablation-submission.md](exp08-exp09-stage3-ablation-submission.md)。

四臂各训 3 epoch（每臂 3 h 42 min），配方相对认证 v2 **只改一处**，验证一律 **512 对**
bridged-vs-native 共享噪声 rollout；参照 v2 用 `--validate-only` 在同样 512 对下重读（EXP-09-R）。

## 2. 逐条判定

### EXP-09 A（去掉信赖域）：❌ 否定 —— ρ 在 v2 配方下**从不触发**

判据："否定"= Δ 均值 ≤ 0.05 且 bridged−native 的差 CI 含 0。实测 Δ = **0.0191**（v2 有 ρ 时 0.0196，
几乎一样），bridged 比 native **更好** 0.0134，终点误差 1.2744 与 v2 的 1.2746 无差别。
更直接的证据：**v2 自己的贴边比例只有 0.4%**，去掉 ρ 后 Δ 也只到 1.9% —— 上限从未被逼近。

⇒ 方法节里 ρ **不能**写成"防止漂移的必要机制"，只能写成**防御性截断**：
"在本文的惩罚配置下训练中几乎不触发（贴边 token < 0.5%），它保证的是部署期的最坏情况上界。"

### EXP-09 B（去掉 advantage 加权）：⚠️ 没测出来（但有明确的方向性观察）

判据："否定"= |终点误差差| ≤ 0.01 m **且**一致率在 ±2pt 内。实测终点误差 +0.0038 m（≤0.01 ✓），
但一致率 **0.871 vs 0.766，高出 10.5pt**（超出 ±2pt）⇒ 落在两档之间 ⇒ **没测出来**。

方向性观察（非预注册，只能作描述）：advantage 加权**不改善**终点误差，
但让桥的行为明显更偏离 native（一致率 0.87 → 0.77）。若要写进论文，只能写成
"advantage 加权提高了桥的干预强度，未观察到终点误差收益"。

### EXP-09 C（惩罚退回 v1 值，保留 ρ）：✅ 支持 —— 唯一被证实必要的一项

判据："支持"= 贴边比例 > 0.20 或 preserve 损失 > 10× v2。实测贴边比例 **0.928**
（92.8% 的 token 顶在 ρ 上限），Δ = 0.0494 ≈ 上限 0.05，preserve 5.7×，一致率塌到 **0.432**。

也就是说：**v1 的软惩罚一定会把 Δ 推到上限，是 v2 的惩罚重校准（preserve 2.0 + 相对 Δ 惩罚 ×10）
把 Δ 稳定在 2%**。ρ 之所以"从不触发"，正是因为惩罚重校准在起作用——两者是配套的，
不是各自独立的两道保险。

一个必须一起写出来的反直觉现象：C 的开环终点误差**最好**（1.2594，全部臂里最低），
却离 native 最远（一致率 0.43）。这说明**开环终点误差不能单独用来选配方**——
它奖励更激进的干预，而闭环 SR 对此并不买账（EXP-05：v1 全套激进配方闭环 61.61%）。

### EXP-09 D（选点指标，零成本）：❌ 否定

v2 run 按 rollout 终点误差选的是 epoch 3，按 teacher-forced `val_trajectory_loss` 选的是 epoch 4。
两者在 512 对下重验：**1.2746 vs 1.2743**，差 0.0003 m ≤ 0.005 ⇒ 否定。

⇒ 方法节"模型选择不看训练误差，而看真实生成效果"**降级为流程说明**，
不得声称它带来了更好的 checkpoint。

### EXP-08（阶段二联合训练买到了什么）：❌ 否定

判据的"否定"要求四项同时成立，实测全部满足：

| 指标 | 阶段一父权重 | 阶段二父权重（v2） | 差 | 容差 |
|---|---|---|---|---|
| rollout 终点误差 | 1.2788 | 1.2746 | +0.0042 | ≤ 0.01 ✓ |
| 动作一致率 | 0.779 | 0.766 | +1.4pt | ±2pt ✓ |
| 历史 PCK@8 | 0.9267 | 0.9281 | −0.14pt | ≤ 1pt ✓ |
| 未来 top-k 支持召回 | 0.7685 | 0.7718 | −0.33pt | ≤ 1pt ✓ |

⇒ **阶段二对最终桥的行为没有可测影响**。方法节里"动作监督的梯度必须流入认知分支，
认知才能学到对决策有用的内容"这句**删除**，训练故事简化为"阶段一 → 阶段三"。

**一个未被判据覆盖但更重要的发现**：未来头 Soft-IoU 在阶段一父权重下是 **0.3873**，
在阶段二父权重下只有 **0.2394**（−14.8pt，两者的头都是冻结的，所以这就是阶段二留下的差别）。
即：阶段二不但没给桥买到东西，**还把未来热力图的质量压低了近 15 个点**。

## 3. 合起来对论文意味着什么

阶段三五处改动里，只有**惩罚重校准**被证实有效应；ρ 是它的兜底而非独立机制；
advantage 与 rollout 选点没有可测收益；阶段二对桥无影响且伤害未来头。
方法节的分阶段叙事需要按这个结论收缩，不能逐条宣称必要性。

## 4. 边界

1. **单训练种子**（seed 42），按 2026-09-03 的规划"边缘结论再补种子"。B 臂落在判据夹缝里，
   若要写进论文需补第二个种子。
2. 全部结论建立在**开环 512 对 rollout** 上，不是闭环 SR。开环与闭环的排序并不一致
   （C 臂开环最好、配方最激进，而 EXP-05 显示激进配方闭环并不更好）。
3. 各臂的 native 基线在 1.2878–1.2922 之间（同一 val 集、不同采样噪声），比较一律用同批 native 的差。
4. 只在 v2 数据（`r2r_panoramic_data_v2` + `amb3r_endpoint_v3_full_r2r`）的 val 划分上成立。
