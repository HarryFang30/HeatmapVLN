## 结论

- **H-29 没有检验**：V1 在离线门不过，未上 val。
- 排除了损失加权这个混杂之后，"转圈处停够"和"远处不多停"在这份数据（EXP-23 第一轮的 R2R 训练集记录）上仍然分不开。
- 按预注册的边界，**STOP-only 的 LoRA 训练永久关闭**。
- 兜底照预注册在跑：S1-TM 两种子 val，只作校准，不检验任何提点假设。

## 边界

- 只检验了这一份流（转圈 STOP 3,015 个、锚点、回放），一遍、r32。
  - 不能推出"任何 STOP 监督都没用"；
  - 只能说在这份数据和 LoRA 配方上，两个目标分不开。
- 门是在 cuda 上判的，A 的 G-A 是在 npu 上判的（都与同卡关适配器比）。
