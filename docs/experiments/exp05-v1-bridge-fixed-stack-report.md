## 2. 判据判定

预注册判据："支持"= v1 比 62.8% 低 **> 3pt**；"否定"= 落在 62.8% ± 1.5pt；
"没测出来"= 低 1.5–3pt。实测点估计 **−1.20pt**，落在 ±1.5pt 内 ⇒ **❌ 假设被否定**。

按预注册的后果条款执行：**信赖域的卖点必须改写成"可控性与防御性设计"，
不得声称它挽回了 SR。** 这条在写判据时就答应过要照单接受。

## 3. 这条结果改写了 EXP-01 的病灶归因

EXP-01 当时把 18.11% 记成"病灶 1（桥漂移，小头）+ 病灶 2（评测栈，大头）"的叠加，
但两个变量是同时改的，无法分配权重。现在可以分配了：

| | 缺陷 v3 栈 | 修复栈 |
|---|---|---|
| v1 无约束桥（Δ RMS ≈ 0.7） | 18.11% | **61.61%** |
| v2 信赖域桥 | 13.6%（940 集部分数据） | 62.81% |

**同一个漂移桥，只换评测栈：18.11% → 61.61%，+43.5pt。**
而在修复栈上换桥（v1 → v2）只有 +1.20pt，且置信区间含 0。
所以 62.5% → 18.1% 的崩塌**几乎全部由评测协议缺陷造成**，桥漂移的代价上限约 3pt（CI 上界）。

## 4. 边界

1. **单种子**（协议种子 42）。CI 下界 −3.21pt，所以"漂移桥无害"是不能说的——
   能说的只有"在 1839 集单种子下，它与 v2 的差异不可分辨，点估计约 −1.2pt"。
2. 只对**这个** v1 checkpoint 成立（`run_20260818_225001` 的 EMA 部署权重，
   桥 out_proj 权重 RMS 0.0032，是 v2 的 5 倍）。不同随机种子重训的无约束桥可能漂得更远。
3. 只在 R2R val-unseen 上成立；未跨数据集验证。
4. v1 与 v2 的差异不止信赖域一项（还含 advantage、惩罚校准、选点指标），
   本实验测的是**整套配方**的闭环价值，逐项拆分见 [EXP-09](README.md#exp-09-阶段三配方里哪一项真的在起作用)。
