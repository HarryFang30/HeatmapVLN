# EXP-21 参数敏感性（任务 4）

**问题**：三个**推理期**参数各自偏离部署值时，闭环表现怎么变。都不用重训。
**图**：`scripts/exp21/figures/fig_sensitivity.py`，输出 PDF / SVG（文字可编辑）/ PNG 400 dpi / 图注，中英双语。
**数据**：`exp21-sensitivity-results.json`（本目录，含两平台 18 个点的配对结果，可离线重建图）。

| 参数 | 是什么 | 部署值 | 扫的值 | 在哪一侧 |
|---|---|---:|---|---|
| **K** 历史帧数 | 同时改慢系统收到的历史帧**和**历史认知头的输入；训练时用 5–8 帧 | 8 | 5, 6, 7 | 客户端 `--num_history` |
| **S** 采样条数 | 每次规划从这些样本的**均值路径**出动作 | 32 | 1, 8, 64 | 服务端 `--nextdit_num_sample_trajs` |
| **M** 去噪步数 | 快系统流匹配的步数 | 10 | 2, 5, 20 | 服务端 `--nextdit_num_inference_steps` |

**判据（预注册）**：每个点与**同平台自己的默认点**、同种子（42）、同 500 集做配对 bootstrap（2000 次）。
**SR 的 95% CI 不含 0 → 「敏感」，否则「在噪声内」。**

---

## 2. 结果：昇腾 910B（跨平台复现）

默认点是 910B 上**重跑的**同 500 集，SR 62.00 / SPL 54.78 / NE 3.939。

| 参数 | 值 | SR (%) | ΔSR (95% CI) | 判定 |
|---|---:|---:|---|---|
| **K** | 5 / 6 / 7 | 59.00 / 62.60 / 61.60 | −3.00 [−7.20, +1.00] / +0.60 [−3.40, +4.20] / −0.40 [−4.00, +3.20] | 全部在噪声内 |
| **S** | 1 / 8 / 64 | 61.60 / 64.00 / 62.80 | −0.40 [−4.20, +3.20] / +2.00 [−1.80, +5.60] / +0.80 [−2.40, +4.00] | 全部在噪声内 |
| **M** | 2 / 5 / 20 | 63.40 / 61.20 / 64.60 | +1.40 [−2.20, +5.00] / −0.80 [−4.20, +2.40] / +2.60 [−0.40, +5.40] | 全部在噪声内 |

**910B 上没有任何点判为敏感。** K=5 的方向与 4090 一致（−3.00 vs −6.20）但 CI 含 0。

## 3. 结论

**唯一敏感的是 K（历史帧数），而且只在 4090 上达到显著。**

- **K**：掉到 5 或 6 帧，SR 下降 **5.8–6.2 pt**，CI 不含 0；K=7 已经回到噪声内。
  K=5 的 ΔNE 也显著（+0.395 [+0.068, +0.693]）。**这推翻了预注册的先验**，
  先验以为 5–7 帧都在训练范围内、变化会在噪声内。
  合理的解释是 K 同时改了慢系统的输入**和**历史认知头的输入，是三个参数里唯一触及慢系统的。
- **S**：从 32 降到 **1** 都在噪声内（−1.80 [−5.40, +2.00]）。**也推翻了先验**
  （先验以为 S=1 会明显变差，因为没有均值平滑）。
  与实时性数据一致：NextDiT 采样只占模型服务端的 5.5%，S 不是瓶颈也不是效应来源。
- **M**：从 10 降到 **2** 都在噪声内（−2.80 [−6.40, +0.60]）。**同样推翻先验。**

**三条先验里，两条被推翻、一条反向。** 这是预注册的价值所在：判据在看到任何数字之前写死，
所以这里只能照实报，不能事后改口径。

**可操作的结论**：想省算力就降 S 和 M（降到 S=1、M=2 都没测出代价，而 M=2 能省掉 NextDiT 的 80% 步数）；
**不要降 K**。

## 4. ⚠️ 子集偏差（按预注册如实写明，子集未改）

| | SR (%) |
|---|---:|
| 默认点在这 500 集上（4090） | **65.80** |
| 全量 1839 集（4090 A0 种子 42） | 62.70 |
| 差 | **+3.10 pt** |

判据写的是「差应在 ±3 pt 内；**超出就在图注里写明子集偏差，不改子集**」。实测 +3.10 pt，
**刚刚超出 0.10 pt**，所以按预注册的处理：**写明，不改**。

影响：**本图的绝对水平整体高于主表**，不能把 65.80 和主表的 62.70 并列。
**配对差值不受影响** —— 每个点都与同一子集上的默认点配对，子集难度在差值里抵消掉了。

## 5. 边界

- **两个平台的绝对数不可比，从不合并。** 同样 500 集，4090 是 65.80、910B 是 62.00，差 3.8 pt。
  图里把两条线放在一起**只为比较响应的形状**，不是同一个量的两次测量（台账 EXP-22 §3）。
- **种子只有一个（42）。** 消融表里两个种子的 A0 相差 1.96 pt，而这里好几个点的 ΔSR 比这还小，
  所以「在噪声内」的那些点换个种子完全可能换个符号。**不要把点估计的方向当结论。**
- **一次只改一个参数**，没有测交互；K 与 M 同时降会怎样，这组实验答不了。
- 910B 上 K=5、S=64、M=2 三个点是在第一台实例被停之后、在第二台上续跑完的，
  它们的 `progress.json` 里有两个端口块，审计要按两套核（见 `exp21-ascend-run-notes.md`）。
