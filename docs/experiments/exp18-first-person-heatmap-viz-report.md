# EXP-18 报告：第一视角拓扑热力（affordance map）准不准、换场景还准不准

预注册与判据见台账 [README.md](README.md) 的 EXP-18 条目，复现见 [runbook](exp18-first-person-heatmap-viz-runbook.md)。
本文件只放证据链；结论以台账为准。所有数字出自 `model/exp18_first_person_viz/metrics/`（路径相对
`/mnt/afs/liwenhao/agent/370910109/`），由 `scripts/exp18/compute_metrics.py` 生成，`--self-check` 用
`scripts/training/validate.py::_HeatmapJointMetricAccumulator` 逐层逐臂复算 joint PCK@8，全部逐位相同。

## 1. 被测对象与口径

- **头**：部署权重 `model/exp03_deployment_head/head_v2_best.pth`（`initial_head_hash=e00d5058…`），按
  `configs/train_heatmap_internnav_single_view_8gpu.yaml` 构建，eval 模式；输入 = 当前前视图 + 8 个历史前视图 + 相对位姿。
- **两个位姿臂**在同一组查询行、同一份视觉特征上各跑一次头：VO 臂（AMB3R 端点缓存，部署设置，**判据臂**）、GT 臂（Habitat 真值，
  只用于拆分头与里程计）。查询行 = 缓存端点（t = 19, 27, 35, …，外加末帧），历史帧 = `linspace(0, t−1, 8)`。
- **标签**：与训练同一个 `_compute_per_history_multiview_heatmaps`；左/右/后视不做遮挡判断（只有前视有深度），与训练一致。
- **指标**：joint PCK@8（5 路视角分类正确且 GT 视角内 argmax 距离 ≤ 8 px；分母 = GT 可见槽位）；方位误差 = 预测峰值方位与
  `atan2(left, forward)` 的圆周差；可见性 = `1 − P(none)` 对"任一视角可见"的 AUROC；平凡基线 = 恒判后视中心像素。
  标签与几何自洽：GT 标签峰值与位姿方位最大差 0.91°（P99 0.87°），GT 视角类与方位扇区一致率 99.86–99.92%。
