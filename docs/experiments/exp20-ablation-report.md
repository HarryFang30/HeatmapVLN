**平台**：RTX 4090，全部四个臂、两个种子都在同一台机器上，所以表内任意两行可比。
**数据**：R2R-CE val_unseen 全量 **1839 集**，指标 SR / SPL / OS / NE。
**判据**：预注册（台账 EXP-20），每个臂与 A0 **同平台、同种子、同集**做配对 bootstrap（2000 次，
`scripts/tools/paired_closed_loop_bootstrap.py`），两种子合并后看 ΔSR 的 95% CI。
CI 不含 0 且 A0 更好 → 支持；CI 不含 0 且臂更好 → 否定；**CI 含 0 → 没测出来**。

## 5. 边界（这张表不能推广到哪里）

- **只在 4090 上成立。** 910B 上有它自己的 A0 参照，两台机器的绝对数不能混（台账 EXP-22 §3）。
- **平台一致性只核对了总数。** A0 两种子与已停用的 C500 相差 −0.11 / −0.43 pt，都在 ±2 pt 内，
  但判据要的是**配对**差，而 C500 的逐集结果没有迁出来，所以配对检查做不了。
- **「没测出来」不等于「没有差别」。** 1839 集、两种子的功效只够分辨约 1.2–1.9 pt 的 SR 差（看 CI 宽度），
  更小的真实效应这组实验看不见。
