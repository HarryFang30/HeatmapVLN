# HeatmapVLN 热力图 Loss 设计建议

## 1. 问题定义

当前任务不是普通的语义分割，而是更接近一个两阶段问题：

1. 判断某个历史帧在当前 view 中是否真实可见。
2. 如果可见，在当前观测中画出该历史帧相机位置对应的亮点热力图。

这两个子问题高度相关，但不完全等价。当前训练中最核心的困难不是“把亮点画尖”，而是：

- 模型容易把“看过类似场景”误判为“这就是目标历史帧位置”。
- GT 热力图极度稀疏，大部分像素严格接近 0。
- 部分样本 GT 全零，属于真正的不可见负样本。

因此，loss 的首要目标不是追求分布好看，而是：

- 强抑制负样本假阳性。
- 防止模型通过输出全黑图逃避训练。
- 防止模型用单像素亮点或窄条带投机取巧。

## 2. 现有 `QFL + coord + vis` 为什么比旧方案更好

相对旧版“多个彼此目标不完全一致的 loss 叠加”，当前方案的进步是成立的：

- `QFL` 比简单 `L2 neg_loss` 更适合处理大假阳性。
- `coord_loss` 给正样本一个显式的位置约束。
- `vis_loss` 单独监督“是否可见”。

这一方向是对的，因为当前 GT 形态本质上是“稀疏亮点 + 大片零背景”，单纯依赖 L2、KL 或归一化分布损失都不够针对。

但是，这个方案还不是最优，原因有三点：

1. 训练时监督的是 raw heatmap，推理时才乘 `visibility`，训练目标和推理行为不一致。
2. `QFL` 虽然能更强地打假阳性，但无法单独阻止“整体偏暗”甚至“全黑”坍缩。
3. `coord_loss` 和任何 `max` 风格约束都可能诱导模型走向单像素尖峰或细条带这种便宜解。

## 3. 必须继续防的 4 个风险

### 3.1 全黑坍缩

如果只监督最终 gated heatmap：

`h_final = sigmoid(vis) * h_loc`

模型最容易学到的捷径就是：

- `sigmoid(vis) -> 0`
- `h_loc -> 无所谓`
- `h_final -> 全黑`

这会在负样本很多时尤其严重。

### 3.2 正样本亮度不足

即使位置大致对，如果缺少对正样本亮度或局部质量的单独约束，模型可能倾向于输出“位置差不多对，但整体偏暗”的热力图。  
这会表现为：

- GT 最大值很高，但预测最大值始终偏小。
- 可视化上能看到模糊响应，但峰值起不来。

### 3.3 单像素尖峰正反馈

如果 loss 过度关注 `max`、坐标或最亮点，模型可能在一个像素上堆出异常高响应，以快速优化这些指标。  
这会造成：

- 峰值坐标看起来变准了。
- 但热力图形状从高斯 blob 退化成尖刺。

### 3.4 窄条带投机

如果只要求“亮、位置差不多”，而没有要求“局部形状合理”，解码器很容易学出一条细亮带：

- `max` 很高。
- soft-argmax 坐标可能也不差。
- 但空间形状明显不符合 GT 的各向同性亮点。

## 4. 更优的总体思路

最优方向不是继续堆一个更强的单项 loss，而是显式把任务拆成：

- `visibility branch`: 学“该不该亮”
- `location branch`: 学“该亮时亮在哪里”
- `final map supervision`: 学“最终输出行为必须正确”

定义：

- `p_vis = sigmoid(vis_logit)`
- `h_loc = raw location heatmap`
- `h_final = p_vis * h_loc`

其中：

- `h_loc` 表示“如果这个历史帧真的可见，它应该出现在哪里”
- `h_final` 表示“模型最终交付给推理的热力图”

这样设计的好处是：

1. 把“是否存在”和“位置在哪里”解耦。
2. 训练目标与推理目标一致。
3. 假阳性梯度能同时回传给可见性分支和定位分支。

## 5. 推荐的最终 loss 组合

我建议使用下面 4 项作为主方案：

### 5.1 `L_vis`: 可见性损失

对 `vis_logit` 使用带类别不平衡处理的二分类损失：

- 首选：`focal BCE`
- 备选：`asymmetric BCE`

作用：

- 学“这个历史帧在当前 view 中到底在不在”
- 防止最终仅靠热力图分支去猜“是否存在”

### 5.2 `L_final_qfl`: 最终热力图主监督

对最终图监督，而不是只监督 raw location：

`L_final_qfl = QFL(h_final, gt_heatmap)`

作用：

- 直接约束推理时真正使用的热力图
- 强力压制负样本假阳性
- 让 `visibility` 和 `location` 共同为最终输出负责

说明：

- 这项是主力，但不能单独使用，否则存在全黑坍缩风险。

### 5.3 `L_pos_mass`: 正样本局部质量损失

这项是整个方案里最关键的补充项。

只在 `gt_vis = 1` 的正样本上计算，约束预测在 GT 峰附近必须有足够的能量和合理的局部分布，而不是只亮一个点或整体偏暗。

推荐做法：

1. 从 GT 中取高响应区域掩码，例如 `gt_heatmap >= 0.3 * gt_max`。
2. 计算预测在该区域内的平均值或积分质量。
3. 用 `1 - mean(pred_in_mask)` 或 BCE 风格损失约束其不能过低。

这项损失同时对抗以下问题：

- 防止全黑坍缩
- 防止正样本峰值始终起不来
- 防止单像素尖峰
- 防止细条带把能量放错位置

相比直接约束 `pred.max()`，它更稳，因为它要求的是“局部一片区域要亮起来”，而不是某一个像素越亮越好。

### 5.4 `L_coord`: 小权重坐标辅助损失

继续保留 soft-argmax 坐标损失，但只作为辅助项，权重要小。

作用：

- 帮助模型把响应中心快速拉向目标位置

限制：

- 不能把它当主监督
- 否则会诱导模型追求尖峰或局部极亮点

## 6. 不推荐作为主力的设计

### 6.1 只用 gated heatmap 做单一监督

不推荐原因：

- 容易坍缩成全黑图
- 模型会优先学会“关门”而不是“找位置”

### 6.2 用 `pred.max()` 直接对齐 GT 最大值

不推荐原因：

- 容易导致单像素爆亮
- 不能约束空间形状
- 容易放大奖励黑客解

### 6.3 用强形状正则硬逼近高斯

不推荐作为第一优先级原因：

- 数据里的 GT 受距离衰减、遮挡、投影和多样化局部几何影响，不一定总是理想各向同性高斯
- 过强形状正则可能压制模型对真实数据分布的适应性

更稳的做法是先用 `L_pos_mass` 这种“局部质量约束”，而不是直接把 GT 当作理论高斯模板硬拟合。

## 7. 推荐公式

定义：

- `p_vis = sigmoid(vis_logit)`
- `h_final = p_vis * h_loc`
- `M_pos = (gt_heatmap >= tau * gt_max)`，例如 `tau = 0.3`

推荐总损失：

```text
L_total
= 1.0 * L_vis
+ 1.0 * L_final_qfl
+ 0.5 * L_pos_mass
+ 0.2 * L_coord
```

其中：

- `L_vis`: `focal_bce(vis_logit, gt_vis)`
- `L_final_qfl`: `QFL(h_final, gt_heatmap)`
- `L_pos_mass`: 仅在正样本上计算，约束 `h_final` 或 `h_loc` 在 GT 峰附近不能太暗
- `L_coord`: 仅在正样本上计算 soft-argmax 坐标误差

## 8. `L_pos_mass` 监督 `h_loc` 还是 `h_final`

这里建议分阶段看：

### 更稳的默认选择：监督 `h_loc`

优点：

- 更能防止 gating 把定位分支完全压死
- 让定位分支持续学习“亮点应该长什么样”

适合训练前期或模型还不稳定时使用。

### 更贴近推理目标的选择：监督 `h_final`

优点：

- 训练目标与推理行为最一致

缺点：

- 如果 gating 太强，会增加坍缩风险

### 实际建议

最稳妥的做法是：

- `L_final_qfl` 监督 `h_final`
- `L_pos_mass` 和 `L_coord` 监督正样本上的 `h_loc`

这样可以同时做到：

- 最终行为正确
- 定位分支不被 gating 压死

## 9. 训练策略建议

为了进一步降低坍缩风险，建议加入简单训练策略，而不是只改公式：

### 9.1 两阶段训练

阶段一：

- 先训练 `h_loc`
- `visibility` 分支正常训练
- 但 `L_pos_mass` 和 `L_coord` 重点放在 `h_loc`

阶段二：

- 再提高 `L_final_qfl` 的作用
- 让 gated 最终图逐步承担主要监督

### 9.2 gating warmup

不要一开始就让 gating 的影响过强。可以采用：

- 前若干 epoch 对 `h_final` 使用较弱 gating
- 或者前若干 epoch 提高正样本 `L_pos_mass` 权重

### 9.3 指标不要只看 loss

验证时至少同时看：

- 负样本上的 `max(h_final)`
- 正样本上的 GT 峰区域平均响应
- 假阳性比例
- 峰值坐标误差

否则很容易出现“loss 在降，但模型学会了全黑”或“loss 在降，但图变成单像素尖刺”。

## 10. 最终结论

对当前任务，单纯把旧 loss 替换成 `QFL + coord + vis` 是一个正确改进，但还不是最优解。  
更优的方案是：

1. 训练时就监督最终 gated map，而不是只在推理时使用 gating。
2. 保留独立的可见性监督。
3. 在正样本上增加局部质量约束 `L_pos_mass`，防止全黑、弱峰、单点和条带投机。
4. 坐标损失仅保留为小权重辅助项。

如果只能选一个最值得增加的新项，那么优先级最高的是：

`L_pos_mass`

原因是它能同时缓解：

- 全黑坍缩
- 正样本峰值过低
- 单像素爆亮
- 细条带投机

因此，我认为当前任务的最优 loss 方向不是“再换一个更猛的像素误差”，而是：

**`visibility`、`final map`、`positive local mass` 三者联合建模。**
