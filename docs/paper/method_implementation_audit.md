## 关键冲突与写作边界

- “冻结 Qwen”不等于“不运行 Qwen”。Heatmap-only 阶段只执行冻结的 `Qwen.visual`；完整导航会执行冻结的完整 Qwen2.5-VL。
- AMB3R 适配训练已在代码中实现并通过真实单卡/多卡 smoke，但正式 endpoint-v2 全量 cache 与适配 checkpoint 在审计时尚不存在；不能把未产出的权重写成已完成实验。
- 现有 System-1 control 训练数据的 `history_rel_poses` 仍由专家/DAgger GT c2w 计算，现有 control checkpoint 也与旧 Head 依赖绑定。它没有在 AMB3R-adapted Head 的输出分布上训练。
- endpoint-v2 cache 只覆盖固定 map-update endpoint 加 final；在线 System-2 可在任意 replan 时提前 flush tail。二者是因果的近似分布，不是严格同分布。
- “推理不使用 GT”目前只对 AMB3R opt-in 的模型输入路径成立；当前 formal/full navigation 入口仍读取 Habitat c2w，评测环境也可保留 privileged sensor 供 simulator metrics 使用。
